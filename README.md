# 뽀득뽀득 (Squeak Squeak)

> 더러운 동전을 정성스럽게 닦고, 표면을 복원하고, 반짝이는 결과물을 모으는 탑뷰 3D 클리닝 시뮬레이션 게임.

**뽀득뽀득**은 작업대 위에 놓인 작은 물체를 다양한 도구로 청소하는 Unity 3D 게임 프로젝트입니다. 첫 번째 청소 대상은 **낡고 더러운 동전**입니다. 플레이어는 마우스로 도구를 움직여 먼지와 흙을 제거하고, 표면의 얼룩을 닦고, 마지막으로 금속 광택을 되살립니다.

작은 물체 하나가 손길에 따라 깨끗해지는 과정과 완성된 결과물을 바라보는 만족감을 중심으로 개발합니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 3D 클리닝 시뮬레이션 / 수집형 반복 작업 게임 |
| 엔진 / 언어 | Unity 3D / C# |
| 현재 프로젝트 Unity 버전 | 6000.3.23f1 |
| 목표 플랫폼 | PC |
| 시점 | 작업대 위 물체를 내려다보는 탑뷰, Orthographic Camera |
| 주요 조작 | 도구 선택 및 마우스 드래그 |
| 초기 청소 대상 | 가상의 디자인을 가진 낡은 동전 1종 |
| 목표 플레이 시간 | 동전 1개당 3~5분, 첫 MVP 데모 약 5분 |

현재는 **Step 0 개발 기반 검증 단계**입니다. `CleaningRoom`에 탑뷰 카메라·조명·임시 작업대·동전을 구성했습니다. 아래의 청소 시스템과 플레이 흐름은 구현 목표이며, 입력 동작은 아직 연결하지 않았습니다.

## 현재 씬과 조작 계획

Unity `6000.3.23f1`에서 `Assets/Scenes/CleaningRoom.unity`를 열고 Play Mode로 기본 배치를 확인합니다.

초기 개발 단계의 빌드 시작 씬은 `CleaningRoom`입니다. 제품명은 **Squeak Squeak**, 기본 화면은 **1280×720 창 모드(크기 조절 불가)**로 설정합니다.

확정 키맵: **Mouse Move** 도구 이동 / **LMB Hold·Drag** 도구 사용 / **MMB Drag** 동전 자유 회전 / **Mouse Wheel** 확대·축소 / **F** 동전 위치·회전·Zoom 초기화. 실제 동작은 Step 1에서 구현합니다.

씬 구성, 설정 상태, Windows 빌드와 다른 PC 재현 절차는 [Step 0 검증 기록](Docs/Step0-검증.md)을 참고하세요.

## 게임의 방향성과 핵심 재미

플레이어는 캐릭터를 이동시키는 대신 선택한 도구를 손처럼 움직여 동전 표면을 직접 닦습니다. 청소할 위치와 사용할 도구를 고르고, 문지른 자리에 나타나는 변화를 확인하는 행동이 플레이의 중심입니다.

- **깨끗해지는 시각적 만족감:** 먼지와 흙이 떨어지고, 얼룩이 옅어지며, 가려져 있던 동전 표면이 드러납니다.
- **직접 문지르는 손맛:** 도구의 움직임에 맞는 제거 효과와 소리로 작업에 대한 즉각적인 피드백을 제공합니다.
- **도구를 고르는 판단:** 오염의 성질과 청소 단계에 따라 적합한 도구를 선택합니다.
- **광택으로 완성되는 보상감:** 청소를 마친 동전에 금속의 반짝임이 살아나며 작업의 완성을 보여줍니다.
- **수집으로 이어지는 반복 동기:** 장기적으로 완성된 동전을 보관하고 전시하며 다양한 동전과 오염에 도전합니다.

스토리의 비중은 낮게 두고, 청소하는 행위 자체의 만족감에 집중합니다. 특히 닦은 부분과 닦지 않은 부분의 차이, 도구별 반응, 마지막 광택 표현을 중요한 경험으로 다룹니다.

## 핵심 플레이 흐름

```text
더러운 동전 등장
    ↓
오염 상태 확인 → 도구 선택
    ↓
큰 먼지와 흙 제거
    ↓
표면 얼룩과 세부 오염 정리
    ↓
광택 작업
    ↓
완료 판정 → 결과 확인
```

첫 MVP에서는 결과 화면에서 다시 시작할 수 있도록 하나의 청소 루프를 완성합니다. 이후 보상 획득, 동전 수집·전시, 다음 동전 진행을 연결해 반복 플레이로 확장합니다.

## 주요 게임 구성

### 작업 공간과 동전

작업대 위에 동전 하나를 놓고 고정된 탑뷰 카메라로 내려다봅니다. 플레이어가 동전의 오염 상태와 도구가 닿는 위치를 쉽게 파악할 수 있는 구성을 지향합니다. 초기에는 기본 도형과 임시 에셋을 활용하고, 청소 과정이 충분히 작동한 뒤 외형을 다듬습니다.

### 하이브리드 오염 시스템

오염은 성질에 따라 **오브젝트형 오염(A 타입)**과 **표면형 오염(B 타입)**으로 나눕니다. 두 방식을 함께 사용해 큰 이물질이 떨어지는 변화와 표면이 점진적으로 복원되는 변화를 표현합니다.

| 구분 | 주요 대상 | 목표 표현 |
| --- | --- | --- |
| A 타입: 오브젝트형 | 큰 먼지, 흙덩이, 물방울, 찌꺼기 | 도구가 닿으면 개별 오염이 줄어들거나 떨어져 나감 |
| B 타입: 표면형 | 기름때, 산화 얼룩, 얇은 오염막, 표면의 탁함 | 문지른 위치의 오염이 점차 옅어지고 표면이 드러남 |
| 복합 오염 | 겉 찌꺼기와 표면 착색이 함께 있는 검은 때 등 | A 타입과 B 타입을 함께 적용 |

구현은 단계적으로 진행합니다. 처음에는 A 타입의 개별 오브젝트 제거와 B 타입의 수치·색상 변화로 전체 루프를 검증합니다. 이후 위치별 제거, 텍스처 마스크, 머티리얼·셰이더 표현 순으로 발전시킵니다. 광택은 별도 상태로 관리하며 표면의 반짝임 변화로 보여줍니다.

### 도구 3종

| 도구 | 주요 역할 | 플레이에서의 특징 |
| --- | --- | --- |
| 마른 천 | 가벼운 먼지, 물기, 얇은 표면 오염 제거 | 기본 도구. 제거력은 비교적 약하지만 부담 없이 사용 |
| 작은 솔 | 흙덩이, 큰 찌꺼기, 홈 사이 오염 제거 | A 타입 오염 제거에 효과적이며 광택은 올리지 않음 |
| 광택천 | 마무리 광내기, 반짝임 증가 | 광택 상승에 특화되며 오염이 많이 남으면 효과가 낮음 |

도구마다 오염 제거 효율과 광택 효과를 다르게 설정해, 동전의 상태를 보며 도구를 바꾸는 흐름을 만듭니다. 구체적인 수치와 사용감은 플레이 테스트를 통해 조정합니다.

### 진행 상태와 결과 화면

플레이 중에는 도구 선택 상태와 청소 진행률을 보여주고, 완료 후에는 **청결도, 광택도, 완료 시간**을 표시합니다.

MVP 완료 조건의 기획 예시는 다음과 같습니다. 실제 기준은 조작감과 플레이 시간을 확인하면서 조정합니다.

- A 타입 오염 제거율 90% 이상
- B 타입 표면 오염 제거율 80% 이상
- 광택도 70% 이상

## 첫 MVP의 범위

첫 번째 목표는 **동전 하나를 청소하고 광을 낸 뒤 결과 화면까지 도달하는, 실행 가능한 작은 데모**입니다.

포함할 기능은 다음과 같습니다.

- 작업대, 동전 1개, 탑뷰 카메라
- 마른 천·작은 솔·광택천 선택
- 마우스 드래그를 통한 청소 조작
- A 타입 오염 제거와 기초 B 타입 표면 변화
- 광택 변화 및 진행률 표시
- 완료 조건 판정과 결과 화면
- 다시 시작 기능
- PC에서 실행 가능한 첫 빌드

여러 동전, 랜덤 오염 생성, 상점, 도구 강화, 세이브·로드, 전시 공간 이동, 복잡한 경제 시스템은 MVP 이후로 미룹니다. 고급 셰이더와 정교한 사운드 시스템도 후속 개선 대상으로 두되, 기본적인 시각·조작 피드백은 초기부터 확인합니다.

## MVP 이후의 확장 방향

1. **스테이지와 도구 학습:** 먼지, 흙, 표면 얼룩, 광택 저하 등 새로운 상황을 단계적으로 소개합니다.
2. **청소 표현 개선:** 닦은 위치에 따라 오염이 사라지는 마스크와 금속 광택 표현을 발전시킵니다.
3. **다양한 작업 대상:** 동전 종류와 오염 조합을 늘리고 새로운 도구를 추가합니다.
4. **수집과 전시:** 완성한 동전을 유리병, 앨범, 진열장 등에 보관하는 경험을 만듭니다.
5. **반복 플레이:** 랜덤 오염 동전, 결과 등급, 보상, 도구 구매·강화를 연결합니다.

장기적으로는 다양한 도구와 동전을 경험하는 2시간 이상의 플레이와, 랜덤 오염을 통한 반복 플레이를 지향합니다. 이 범위는 첫 MVP의 완성도와 테스트 결과에 따라 확장합니다.

## 개발 원칙과 구성 방향

- 동전 하나의 청소 루프를 먼저 완성하고 기능을 작은 단위로 추가합니다.
- 그래픽 고도화에 앞서 조작감과 눈에 보이는 반응을 검증합니다.
- A 타입과 B 타입 오염을 구분해 관리하고, 표현 방식을 단계적으로 개선합니다.
- 입력, 도구, 오염, 동전 상태, 게임 진행, UI의 역할을 나누어 구성합니다.
- 씬·오브젝트·스크립트의 연결 관계와 현재 구현 상태를 문서로 남깁니다.
- 변경한 동작은 Unity 에디터에서 확인하고 실행 가능한 빌드로 검증합니다.

플레이 씬은 `CleaningRoom`이며 현재 작업대·임시 동전·탑뷰 카메라·조명이 있습니다. 이후 도구 커서와 동전의 오브젝트형 오염·표면 오염·광택·상태 관리 역할을 추가하고, 게임 진행·도구 선택·진행률 UI·결과 화면을 연결할 예정입니다.

현재 주요 디렉토리는 다음과 같습니다.

```text
├─ Assets/            Unity 에셋, 씬, 스크립트

```
