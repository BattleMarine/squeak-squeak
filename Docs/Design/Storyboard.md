# 뽀득뽀득 화면과 인터랙션 스토리보드

갱신일: 2026-10-15

작은 코지한 방에서 동전을 닦고, 같은 방의 유리병이나 벽에 보관하며 다시 감상하는 경험을 설계한다. 화면의 미려함보다 **무엇을 보고, 어떻게 조작하며, 무엇이 반응하는지**를 분명히 보여준다. 장소 이동은 방 안에서 사람이 일어나 돌아보고 다시 앉는 연속적인 카메라 움직임으로 연결한다.

이 문서는 대화의 인터랙티브 스토리보드 30개 장면을 바탕으로, 첫 화면과 공간 이동 연출 및 [동전 상태와 청소 경험 설계 원칙](CoinCleaningPrinciples.md)을 반영한 설계 기준이다. 기존 장면 번호는 유지하고 관찰·시험·손상 징후·결과 확인 장면을 추가했다. 카메라 동작표는 기존 장면 사이에 들어가는 세부 동작이며 별도 게임 화면이나 로딩 화면을 뜻하지 않는다. 기존 인터랙티브 시안에는 이 문서의 연속 카메라 동작과 청소 원칙 개정이 아직 반영되지 않았다.

## 방향과 결정 상태

### 사용자 요청으로 정해진 방향

- 분위기의 참고작은 **Undusted: Letters from the Past**다. 물체와 작업 반응에 집중하고 UI는 이를 보조한다.
- 공간은 다락방 또는 서재 같은 작은 코지한 방이다. 작업대와 전시장 또는 책장이 한 공간 안에 있다.
- 작업대에서 동전을 닦고, 완성된 동전은 유리병이나 벽 진열 등에 남는다.
- 도구는 현재 3종에 한정하지 않는다. 동전도 여러 종류·재질·노출 환경을 갖는다.
- 표면 상태는 먼지·얼룩·광택 외에 녹·착색·닳아 매끈해진 부분 등을 포함할 수 있다.
- 스토리보드는 여러 화면의 **입력 전 상태 → 조작 → 반응 → 다음 상태**를 설명한다.
- 작업대와 전시장을 오갈 때 컷 전환 없이, 일어나 뒤를 돌아보는 듯한 시점 이동으로 연결한다.
- 첫 화면은 블러 처리된 방 전경이다. 시작하면 자연스럽게 작업대 앞에 자리를 잡아 앉는다.
- **대상의 상태는 다양하게, 도구와 조작은 간결하게, 반응은 재질과 상태에 따라 다르게** 만든다. 아래 장면은 청소 원칙을 구체화한 제안이며 도구 목록·수치·손상 한계의 구현 승인을 뜻하지 않는다.
- 관찰 → 작은 부위 시험 → 반응 확인 → 도구·작업 조절 → 목표에 맞는 마무리를 기본 흐름으로 삼는다. 모든 동전에 여러 검사나 동일한 시험 절차를 강제하지 않는다.
- 제거할 오염, 보존할 표면, 기존 손상, 작업으로 새로 생긴 손상을 구별한다. 완료는 최대 광택이 아니라 목표 달성과 표면 보존으로 판단한다.

### 이번 설계의 제안과 미확정 항목

| 항목 | 설계 제안 | 아직 정하지 않은 부분 |

| 보관 | 미리보기 후 위치 확정, 한 동전은 한 위치에 보관 | 병의 용량제, 정렬·이동·회수 방법 |
| 연출 | 짧고 부드러운 이동, 환경음 연속 유지 | 이동 시간·회전각·블러 강도·손과 몸의 표현 |

현재 README의 고정 탑뷰 Orthographic 작업 화면은 현 구현의 설명이다. 여기의 방 탐색·연속 이동·보관 및 확장 UI는 최종 방향을 위한 설계이며 구현 완료를 뜻하지 않는다. 재질 사례와 수치도 설명용이다. 재질만으로 마감 목표를 일괄 결정하지 않고 동전별 표면과 의도한 결과를 함께 정의한다.

## 공간과 전체 동선

창문, 작업대, 책장과 유리병, 벽 진열을 서로 알아볼 수 있는 한 방에 배치한다. 전시 공간은 작업 중 시선의 뒤쪽 또는 뒤쪽 측면에 두는 구성을 우선 검토한다. 정확한 배치는 방 블록아웃에서 결정한다.

```text
블러 처리된 방 전경과 시작 메뉴
  → 시작 선택
  → 블러 해제 + 작업대로 접근 + 착석
  → 대기 동전 선택 → 목표와 표면 관찰 → 도구 선택
  → 작은 부위 시험 → 반응 확인 → 도구·작업 조절 → 청소
      ↖ 필요하면 예비 세척 후 다시 관찰 ↙
  → 목표에 맞는 마무리 → 목표 달성과 표면 보존 확인
  → 완료 동전 감상 → 결과 확인
  → 시선 들기 → 일어서기 → 뒤돌아보기 → 전시장 접근
  → 유리병 또는 벽 진열 미리보기 → 보관 확정 → 다시 감상
  → 작업대 쪽으로 돌아보기 → 접근 → 착석
  → 진행 중 작업 재개 또는 다음 동전 선택
```

도착 지점만 바꾸지 않고 이동 중에도 작업대 모서리, 창문, 책장 같은 공간 기준물이 보이게 한다. 시작·작업·보관 화면이 같은 방에 속한다는 것을 가구 위치와 빛의 방향으로 확인할 수 있어야 한다.

장면 17 → 18 → 02 또는 R1 → R2에 적용한다. 중간에 독립된 방 메뉴 화면으로 잘라 넘기지 않는다. ‘방으로’라는 문구는 같은 방 안에서 시야를 넓히거나 전시 쪽으로 이동한다는 뜻으로 사용한다.

### 공통 전환 규칙 제안

- 방 영상은 연속으로 유지한다. UI가 나타나고 사라지는 페이드는 가능하지만, 장소 이동을 검은 화면·로딩 화면·컷 편집으로 가리지 않는다.
- 이동 중에는 청소·도구 사용·배치 확정과 중복 목적지 입력을 막는다. 도착 후 입력을 복구한다. 이동을 취소할 수 있는지는 별도 결정한다.
- 이동 전에 누르고 있던 마우스 버튼 때문에 도착 즉시 청소·보관이 실행되지 않게 한다. 버튼을 놓고 새로 입력한 조작부터 처리하는 방식을 검토한다.
- 작업을 떠날 때 진행값과 경과 시간을 보존하고, 이동·감상 중 작업 시간 집계는 일시 정지하는 안을 사용한다. 완료 결과는 고정한다.
- 환경음은 끊지 않는다. 도구 마찰음은 작업 종료 때 멈추고, 발걸음·의자·동전 소리는 동작 시점에 맞춘다.
- 급격한 회전과 과한 시점 흔들림을 피한다. 반복 이동의 길이와 모션 감소 옵션은 후속 사용성 검증 대상으로 둔다.
- 현재 작업 화면의 Orthographic 투영과 방의 공간감 사이를 어떻게 연결할지는 구현 검토 사항이다. 특정 카메라 구성이나 패키지 사용을 이 문서에서 확정하지 않는다.

## 장면과 반응

장면은 입력 전 상태를 기준으로 읽는다. ‘반응’은 입력 뒤 일어나야 하는 변화다. 01의 독립 방 탐색은 시작 메뉴를 뜻하지 않으며, 최초 실행에서는 T01~T05 후 02로 진입한다.

### 방과 작업 준비

| 장면 | 입력 전 상태 | 사용자 입력 | 반응과 다음 상태 |
| --- | --- | --- | --- |

## 화면을 구별하는 규칙

- **재질·도금 구조**는 대상의 속성, **제거할 오염**은 처리 대상, **파티나·원래 마감**은 목표에 따라 보존할 표면, **기존 손상**은 시작부터 있던 흔적, **신규 손상**은 작업으로 생긴 변화로 구별한다. **목표 마감**은 원하는 결과다. 이를 하나의 청결도나 광택 수치로 합치지 않는다.
- 도구는 모양·이름·역할을 함께 표시하고 선택 표시를 더한다. **보유·잠김**, **기대 효과**, **표면 위험**을 서로 다른 항목으로 읽을 수 있어야 한다. 세부 정보는 선택 시 보여주고, 작업 중에는 현재 도구와 필요한 단서에 집중한다.
- 상태 표시는 현재 동전에 필요한 항목만 노출한다. 상태 수가 늘어나면 작업 중인 항목과 나머지 상태 요약을 구별하는 방식을 검토한다.
- 관찰 안내는 보이는 단서를 설명한다. 오염 종류·정답 도구·완료 순서를 모두 알려주는 분석표가 되지 않게 한다. 예비 세척으로 새 표면이 드러나면 다시 관찰할 수 있다.
- 위험은 경고 문구만으로 전달하지 않는다. 접촉 부위의 색·질감·형태·반사·소리 변화로 읽히게 하고, 중요한 변화에는 짧은 설명을 보조한다. 신규 손상 판정은 작업 시작 상태와 비교한다.
- 앞면·뒷면·대상 밖을 구분한다. 회전·확대·청소를 같은 제스처로 혼동시키지 않는다.
- 이동 중에는 작업용 HUD가 물러나고 도착한 공간의 상호작용만 나타난다. 환경이 먼저 이어지고 UI가 그 상황을 따라간다.
- 보관 미리보기와 확정된 동전은 반투명 윤곽·확정 표시 등으로 구별한다. 감상만으로 청소 기록을 바꾸지 않는다.

## 목표별로 달라지는 작업 장면

아래는 03 → 07T/07R → 09 → 11R → 13 흐름의 검증 사례다. 실제 재질별 세척 처방이나 확정 도구 조합을 뜻하지 않는다. 같은 도구를 여러 사례에 사용해 반응과 판단이 달라지는지 확인한다.

| 작업 목표 | 관찰·시험 장면 | 작업 중 반응과 선택 | 마무리·결과 화면 |
| --- | --- | --- | --- |
| 일반 세척 | 먼지 아래 얼룩과 기존 패임의 단서를 관찰 | 솔로 먼지를 걷어낸 뒤 같은 도구의 효과를 확인. 필요하면 오염을 풀어주는 도구와 잔여물을 거두는 도구 사용 | 제거 대상과 잔여물이 정리되면 종료. 남은 기존 패임은 미청소나 감점 사유로 표시하지 않음 |
| 표면 보존 | 제거할 이물과 보존할 파티나·원래 마감의 경계를 관찰 | 작은 시험 부위에서 이물이 떨어지고 아래 표면이 유지되는지 확인. 표면 자체가 변하기 시작하면 중단·조절 | 밝아진 정도보다 이물 제거와 보존 상태를 확인. 파티나가 남아도 목표를 충족할 수 있음 |
| 광택 조절 | 문양의 얕은 부분·도금 경계·기존 흠집을 관찰 | 필요한 부위만 연마. 반사가 선명해져도 문양 둔화·도금 손실·함몰이 보이면 손상으로 구별 | 목표 광택과 표면 보존을 함께 확인. 깊은 흠집을 끝까지 지우도록 요구하지 않음 |

도구함은 관찰, 느슨한 오염 제거, 오염 풀기, 잔여물 회수·마무리, 국소 처리, 광택 조절 같은 역할을 중심으로 구성한다. 이는 역할 예시이며 도구 개수를 확정하지 않는다. 크기만 다른 솔이나 효과가 겹치는 세척제는 통합을 우선 검토한다. 한 도구가 여러 상태에 대응하되 모든 상태를 해결하지는 않으며, 효과 차이를 만들기 위해 모든 청소를 느리게 만들지 않는다.

직접 문지르고 표면을 드러내는 조작을 중심에 둔다. 화학 지식·배합·긴 절차 암기를 요구하지 않고, 넣어 두고 기다리는 자동 장비로 핵심 작업을 대체하지 않는다. 액체 도포 등 새 조작을 도입할 때는 입력·반응·종료 조건을 별도로 정하며 기존 문지르기 규칙을 그대로 적용하지 않는다.

## 마모와 손상을 보여주는 연속 장면

09W → 09D → 11R에서는 단순히 색을 지우거나 수치만 올리는 것으로 금속 손실을 표현하지 않는다. 아래 장면의 구현 방식과 깊이 한계는 S3-R 검증에서 결정한다.

| 관찰 대상 | 작업 전 기준 | 작업에 따른 변화 | 회전·확대했을 때 확인할 반응 |
| --- | --- | --- | --- |
| 얕은 문양·돌출 가장자리 | 기존 선명도와 이미 닳은 영역 | 가장자리가 둥글어지고 얕은 문양이 희미해짐 | 빛 방향에 따라 형태 손실이 읽힘. 밝아졌다는 이유로 개선으로 표시하지 않음 |
| 도금 | 기존 벗겨짐과 남은 도금 경계 | 국소 도금 소모 후 바탕 금속 노출 | 노출 부위는 색과 이후 도구 반응이 달라짐. 기존 벗겨짐과 신규 손실을 구별하며 청소로 도금이 복원되지 않음 |
| 흠집·패임 | 시작부터 있던 깊이와 주변 표면 | 얕은 흠집 완화도 주변 재료 손실을 동반. 깊은 흠집·패임은 기본적으로 남음 | 제거를 허용하는 경우 홈을 채우는 대신 주변을 낮추는 변화와 문양·도금의 손실을 함께 보여야 함 |
| 과도한 국소 연마 | 원래의 표면 높이·평탄도 | 해당 부위가 낮아지고 국소 경사가 생김 | 동전을 돌리면 하이라이트 띠가 휘고 반사가 왜곡됨. 거칠기만 바뀐 광택 변화와 구별 |

손상은 누른 시간만으로 동일하게 쌓이지 않는다. 도구의 연마성, 재질, 도금 구조와 현재 표면 상태에 따라 반응을 달리하며 일반 천과 연마제를 같은 금속 제거 도구로 취급하지 않는다. 큰 손상 전에 관찰 가능한 징후를 제공하고, 예고 없이 큰 패널티를 주지 않는다.

표현 범위는 국소 마모·함몰이다. 동전 전체 소실, 관통 구멍, 절단·파편화까지 확장하지 않는다. 오염 표현 A/B 방식과 재질·오염·처리 상태 데이터는 구별하고, 높이·노멀·메시 등 특정 구현을 이 문서에서 확정하지 않는다. 표면 변화와 도구 접촉 표현은 서로 일치해야 한다.

## 후속 검증 기준

- [ ] 시작 메뉴가 흐릿한 방 위에서 읽히고, 시작 후 같은 방의 작업대로 끊김 없이 접근·착석한다.
- [ ] 작업대에서 일어서서 뒤를 돌아보는 중간 구도가 보인다. 가구 위치나 빛 방향이 갑자기 바뀌지 않는다.
- [ ] 유리병·벽 진열에서 작업대로 돌아올 때 회전·접근·착석이 연결된다.
- [ ] 이동 중 중복 클릭이나 계속 누른 버튼이 도착 후 청소·보관으로 잘못 실행되지 않는다.
- [ ] 반복 이동의 길이·회전 속도·흔들림이 부담스럽지 않다.
- [ ] 작업 중 방문과 완료 동전 보관을 구별한다. 복귀해도 처리값과 도구 선택이 보존된다.
- [ ] 도구가 늘어나도 전체 목록 접근이 쉽고 보유·잠김, 효과, 위험을 구별한다. 재질 부적합을 이유로 전부 잠그지 않는다.
- [ ] 관찰 → 작은 시험 → 반응 확인 → 작업 조절을 장면으로 따라갈 수 있고, 익숙한 대상에는 반복 검사를 강제하지 않는다.
- [ ] 같은 도구가 여러 재질·상태에서 풀림·잔여물·표면 노출 등의 다른 반응을 보이며, 속도 차이만으로 구별되지 않는다.
- [ ] 일반 세척·보존·광택 사례에서 목표 달성과 표면 보존이 각각 읽힌다. 최대 광택을 공통 완료 조건으로 요구하지 않는다.
- [ ] 기존 손상이 남아도 미청소·플레이어 실수로 평가하지 않는다. 신규 손상은 별도로 기록되고 이동·보관으로 사라지지 않는다.
- [ ] 큰 손상 전에 표면 변화와 안내를 보고 멈추거나 도구·작업 부위를 바꿀 기회가 있다. 경고·차단 수준은 검증 결과로 정한다.
- [ ] 같은 조명에서 평평한 표면·얕은 마모·국소 함몰을 회전·확대해 비교하고, 하이라이트의 이동으로 거칠기와 평탄도 차이를 구별한다. 정지 화면이나 수치 확인만으로 통과시키지 않는다.
- [ ] 도금 소모·문양 둔화가 표면 변화 및 후속 도구 반응과 일치한다. 손상을 지우기 위한 반복 청소를 유도하지 않는다.
- [ ] 기존의 빠르고 만족스러운 청소 감각을 유지한다. 도구 역할 차이를 만들기 위해 전체 작업을 일괄적으로 늦추지 않는다.
- [ ] 보관 확정 때만 위치·개수가 바뀌고, 취소·중복 입력·용량 부족으로 동전이 사라지거나 복제되지 않는다.

위 항목은 후속 검증 목록이며 검증 완료를 뜻하지 않는다. 청소 방향은 S3-00~02의 기반을 보존한 상태에서 S3-R로 먼저 확인한다. 저장·보상·상점 등 후속 기능과 위 방 이동·전시 연출의 구현 완료 여부는 별도로 관리한다.
