# 동전 상태와 청소 경험 설계 원칙

2026-10-15 · 사용자 합의 원칙. 구현 승인과 콘텐츠 수량 확정은 별도다.

> 동전의 상태는 현실처럼 다양하게, 도구와 조작은 간결하게, 청소 반응은 재질과 상태에 따라 다르게 만든다.

## 1. 풍부한 대상, 간결한 과정

- 재질·층 구조/도금·오염·변색·부식·긁힘·패임·마모를 조합해 실제 더러운 동전을 다루는 느낌을 만든다. 최종 표현 목표이며 모든 상태를 한 번에 구현하지 않는다.
- 현실의 유사 도구·약품을 소수의 게임 도구로 통합한다. 하나의 도구가 여러 상태를 처리하되 하나로 모든 작업을 해결하지는 못하게 한다.
- 큰솔/작은솔처럼 크기만 다른 도구는 하나로 합친다. 구분이 플레이에 기여하지 않는 세척액도 가상 제품 하나로 묶는다. 이는 현실 물질의 성질·호환성이 같다는 뜻이 아니다.
- 복잡한 화학 지식·배합·공정 암기를 요구하지 않는다. 직접 문지르고 걷어내며 표면이 드러나는 경험이 중심이다.
- 초음파·텀블러 등 넣고 기다리면 직접 청소를 대체하는 장비는 기본 범위에서 제외한다. 후반 해금만으로 허용하지 않으며, 재검토 시 직접 작업을 대체하지 않는 역할이 필요하다.

## 2. 관찰과 반응으로 판단

- 같은 도구·같은 조작도 재질, 표면 구조, 오염과 손상 상태에 따라 제거 양상·효과·위험이 달라진다. 단순 속도 차이뿐 아니라 풀림·잔여물·보존 표면 노출 등의 차이를 보여준다.
- 기본 흐름: **관찰 → 작은 부위 시험 → 반응 확인 → 도구 선택/작업 조절 → 목표에 맞는 마무리**. 예비 청소 뒤 다시 관찰할 수도 있다.
- 검사 기능은 재질·상태 판단의 단서를 제공한다. 모든 동전마다 여러 분석 장비를 쓰거나 정답을 암기하게 하지 않는다. 이미 식별한 종류의 반복 검사는 줄인다.
- 색·질감·제거 양상·소리 등 읽을 수 있는 피드백을 제공한다. 큰 손상 전에 위험을 알아차릴 수 있게 하고, 숨겨진 규칙에 따른 갑작스러운 처벌은 피한다.
- 도구의 **소유/선택 가능 여부**와 대상에 대한 **효과/위험**을 구분한다. 부적합 도구를 전부 비활성화해 관찰·시험의 의미를 없애지 않는다. 구체적인 경고·차단 경계는 프로토타입에서 결정한다.

## 3. 상태와 결과 판정

- A/B는 오염의 표현 방식(개별 물체/표면 마스크)으로 유지한다. 별도로 재질·오염 성질·처리 상태를 정의한다.
- 제거할 오염, 보존할 파티나/원래 마감, 기존 손상, 작업 중 새 손상을 구분한다. 기존 패임·마모·도금 손실은 일반 청소로 복구되지 않고 미청소/플레이어 실수로 집계하지 않는다.
- 모든 동전의 최대 광택을 목표로 삼지 않는다. 일반 청소·표면 보존·광택 마감 등 작업 목표에 따라 완료 외관이 달라진다.
- 평가의 중심은 목표 달성과 표면 보존이다. 시간은 보조 기준이며 실제 가중치·등급 경계·손상 허용치는 후속 설계에서 결정한다.
- 기존에 만족한 빠른 청소감은 기준점으로 보존한다. 도구의 만능화는 일괄 감속보다 처리 대상과 역할 구분으로 해결한다.

## 4. 연마·마모·손상의 표현 원칙

**오염 제거와 금속 제거를 구분한다.** 표면이 깨끗해지거나 반짝여도 원래 문양·도금·평탄성이 손실되면 더 좋은 결과로 평가하지 않는다. 아래는 게임에서 지향하는 표현이며 정밀한 금속 가공 시뮬레이션을 요구하지 않는다.

| 현상 | 설계 기준 |
| --- | --- |
| 문양 마모 | 과도한 연마로 돌출부·문자 가장자리가 낮아지거나 둥글어지고 얕은 문양이 희미해진다. 단순히 문양 색만 지우는 효과와 구분한다. |
| 도금 손실 | 국소적으로 외층이 소진되면 아래 금속의 색과 반응이 드러난다. 이후 청소·광택으로 도금이 저절로 복원되지 않는다. 기존 박리와 작업으로 새로 생긴 손실을 구분한다. |
| 얕은 스크래치 | 연마로 완화될 수 있으나 주변 표면 제거와 연결한다. 모든 도구가 동일하게 지우는 오염으로 취급하지 않는다. |
| 깊은 스크래치·패임 | 일반 청소 후 남는 손상을 기본안으로 삼는다. 제거를 허용한다면 홈을 메우는 것이 아니라 주변 높이를 낮추는 과정이며, 인접 문양·도금 손실도 함께 표현해야 한다. 구현 여부와 깊이 경계는 미확정이다. |
| 과연마 함몰 | 같은 부위를 과하게 연마하면 주변보다 낮은 영역과 기울기 변화가 생길 수 있다. 표면이 매끄러워도 하이라이트가 휘거나 반사 방향이 달라져 평탄성 손실을 읽을 수 있게 한다. |

- **제외:** 동전 전체 소멸, 관통 구멍·절단·파편화 등 자유로운 부피 제거는 현재 범위에 포함하지 않는다. 국소 마모와 함몰의 최대 범위는 후속 설계에서 제한한다.
- 마모는 단순한 조작 시간만으로 결정하지 않는다. 도구의 연마 성질·재질·표면 구조·상태에 따라 반응을 다르게 정한다. 일반 천과 컴파운드/연마 도구가 동일한 속도로 금속을 깎는 규칙은 피한다.
- 큰 손실 전에 문양의 둔화·국소 색 변화·반사 띠의 왜곡 등 징후를 보여준다. 멈추거나 도구를 바꿀 판단 기회를 주며, 구체적인 경고/손상 페널티는 별도 확정한다.
- 초기 손상과 작업 손상을 따로 추적한다. 이미 존재한 깊은 홈을 끝없이 연마하도록 완료 조건이 유도해서는 안 된다. 판 재시작은 초기 손상 상태로 돌아가며, 청소로 작업 손상이 자동 회복되지는 않는다.

### 표현 기술 후보와 선택 기준 — 구현 방식 미확정

- **마스크는 상태 데이터:** 오염량과 별도로 위치별 연마량/도금 잔량 등을 기록하는 후보이다. 마스크를 추가하는 것만으로 실제 높이가 변하지 않는다.
- **노멀·거칠기:** 미세 흠집과 얕은 마모의 반사 표현 후보. 거칠기 변화와 표면 기울기 변화는 구분한다. 함몰을 단순한 광택 감소로 대체하지 않는다.
- **높이 정보:** 원래 문양/기존 홈과 누적 재료 제거량에서 최종 표면을 표현하는 후보. 그 기울기로 법선을 계산해 반사에 사용할 수 있지만, 노멀만 바꾸면 실제 실루엣·접촉 위치는 그대로다.
- **실제 표면 변형:** 확대·회전에서 깊이·윤곽·가림이 필요할 때 검토한다. 같은 높이 정보를 메시 변형에도 사용할 수 있으나 해상도·앞뒷면 두께·도구 접촉/충돌 일치·성능을 검증해야 한다. 현 단계의 필수 구현으로 확정하지 않는다.
- 문양·도금·함몰·반사가 서로 모순되지 않게 같은 표면 상태를 참조한다. 단일 맵만으로 모든 현상을 해결해야 한다는 제약은 두지 않는다.
- S3-R에서 평면/얕은 마모/국소 함몰을 같은 조명으로 비교하고 회전·줌 중 반사 이동을 확인한다. 반사 띠가 읽히는 조명에서 평탄성 변화와 거칠기 변화를 구별한다. 정지 이미지나 청소 수치 검사만으로 시각 검증을 대신하지 않는다.

## 5. 도구 규모와 후보 — 확정 목록 아님

사용자 희망 범위는 약 **5~15종**이다. 검사 장비 포함 초기6종·최종8종 안팎은 검증용 제안이며, 역할이 겹치면 통합한다.

| 후보 | 역할 | 도입 제안 |
| --- | --- | --- |
| 검사대 | 확대 관찰·규격/재질 단서 제공; 청소하지 않음 | 초기 |
| 부드러운 솔 | 느슨한 흙·먼지·홈의 부착물 | 초기 |
| 세척액 도포기 | 오염막 처리·불림, 후속 직접 작업 보조 | 초기 |
| 흡수·마무리 천 | 액체·풀린 잔여물 제거 | 초기 |
| 정밀 픽 | 굳은 국소 부착물 제거 | 초기 |
| 광택 도구 | 청소된 표면의 목표 마감 | 초기 |
| 국소 처리 젤 | 일반 세척액과 구별되는 변색/부식 처리 | 후속 후보; 역할 중복 시 통합 |
| 보호 도포기 | 보존 작업의 최종 표면 보호 | 후속 후보 |

실제 효과/위험의 대응표와 조작은 구현 전 확정한다. 특정 재질마다 전용 도구를 하나씩 늘리지 않는다. 액체 도포 등 새 동작에 기존 문지르기 입력 규칙을 기계적으로 적용하지 말고 별도 계약을 정한다.

## 6. 개발 적용

기존 S3-00~02의 완료 이력과 입력·A/B·단계 초기화 기반을 유지한다. S3-03 저장 전에 **S3-R 방향 전환 검증**을 배치한다. 대표적인 일반 청소·보존·광택 작업에서 적은 도구로 서로 다른 판단이 생기는지 확인한 뒤 저장·보상·상점 설계를 확정한다. 복합 형상·정교한 화학 시뮬레이션·대규모 콘텐츠는 이 검증의 필수 조건이 아니다.
