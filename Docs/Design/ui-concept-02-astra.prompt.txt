Use case: ui-mockup
Asset type: high-fidelity art-directed UI concept board for Korean PC game "뽀득뽀득", a top-down 3D coin-cleaning game.
Primary request: Create a fresh, distinctive, polished game UI design proposal titled "뽀득뽀득", concept 02 "작은 수집가의 작업대". ONE portrait presentation board with TWO COMPLETE 16:9 desktop gameplay frames stacked vertically, equally large, slender outer margin and small clean captions. Overall aspect ratio around 4:5. Render at high detail with unusually careful Korean typography and readable concise UI. This is a concept mockup, not an actual screenshot.

ART DIRECTION: bright, contemporary, cozy indie game about care and tactile satisfaction. Milk-white, powder blue, ink navy, soft apricot orange, with the brass coin as the warm visual focal point. Soft stylized 3D objects with matte clay-like simplification and convincing metallic coin highlights; orthographic straight top-down camera. Crisp 2D typography and graphic UI over the scene. Refined cheerful design, slightly playful rounded chunky Hangul wordmark, quiet Swiss-grid spacing, simple 1.5px dark-blue line icons, printed index-card / specimen-label motif. Low-detail pale birch desktop and a powder-blue rectangular cleaning mat with rounded corners. Desktop should feel airy, clean, usable and crafted. NOT photorealistic rustic brown workshop, NOT sage-green/ivory antique treatment, NOT a generic app dashboard, NOT mobile freemium UI. No excessive props, no plant frame, no characters, no bubbles, no sci-fi, no ornate fantasy ornamentation, no device bezel.

Board only: cream-white background. Compact top header with dark navy title "뽀득뽀득" at left and smaller "02 / 작은 수집가의 작업대" at right. Small captions for the two frames: "01  닦는 시간" and "02  반짝이는 순간". No prose blocks outside screens.
