Use case: ui-mockup
Asset type: polished game UI concept presentation for the existing Korean PC game "뽀득뽀득" (Squeak Squeak).
Primary request: Design a beautiful, production-minded first UI concept for a cozy top-down 3D coin-cleaning simulator. Make ONE high-resolution design board with TWO large complete 16:9 desktop game screenshots stacked vertically, upper gameplay and lower completion. Use generous thin presentation margins on a neutral warm ivory board, small heading and panel captions. Overall image approximately portrait 4:5 so each screenshot remains large and text legible. This is a visual proposal, not an existing game capture.

Confirmed gameplay: Mouse drag cleans a dirty fictional bronze coin on a workbench; three tools are dry cloth, small brush, polishing cloth. Track large debris removal, surface stain removal, and polish separately. Mouse middle-button drag rotates, wheel zooms, F resets the view. Finish then admire coin and start a new cleaning. No shop, currency, inventory, grades, rewards, collection menus or extra proposed features.

Design direction: a quiet warm workshop, tactile understated materials, delicate brass accents, sage green active states, ivory UI cards with charcoal lettering. Mature cozy indie PC game style, clean readable modern Korean sans-serif with softly rounded typography; not a mobile game or fantasy RPG. Soft subtle 3D art, wood workbench, restrained light, calm satisfying cleaning. No decorative clutter, bubbles, mascots, cartoon people or arbitrary lore. Light-colored cards sit at edges and do not obstruct the coin. Professional spacing and restrained rounded corners.

Board heading text verbatim: "뽀득뽀득" with small subheading "UI 디자인 시안 · 01". Panel captions "청소 중" and "청소 완료".
