## 1. 실행 준비

1. 프로젝트의 `Builds/Windows/Step2-20261008-S2-06b/` 폴더에서 **SqueakSqueak.exe**를 실행한다. Unity 에디터를 켤 필요는 없다.

3. 마우스 가운데 버튼·휠과 스피커/헤드폰을 준비한다. 시간 검사는 별도 스톱워치도 사용한다.
4. 아래 빌드·PC 정보를 적는다. 새 빌드로 바뀌면 이전 결과와 섞지 않는다.

## 2. 조작과 청소 순서

| 조작 | 동작 |
| --- | --- |
| 마우스 이동 | 도구 커서 이동. 버튼을 누르지 않으면 청소하지 않음 |
| 왼쪽 버튼 누르기/누른 채 이동 (LMB) | 선택한 도구 사용. 한 자리에 누르고 있어도 효과 있음 |
| 가운데 버튼 누른 채 이동 (MMB) | 동전 자유 회전. 뒷면도 돌려서 청소 |
| 휠 | 확대·축소 |
| F | 동전 위치·회전·확대만 초기화. 청소 진행은 유지 |
| 화면 아래 도구 버튼 | 마른 천·작은 솔·광택천 선택 |

기본 진행: **작은 솔로 큰 먼지 → 마른 천으로 앞뒤 얼룩 → 광택천으로 앞뒤 광택 → 결과 → 새 청소 시작**.
세 도구는 효과가 일부 겹칠 수 있지만 작은 솔은 큰 먼지, 마른 천은 얼룩, 광택천은 광택에 특화된다.

## 5. 시간·끊김 기록

- [ ] **M17 / 시간:** 첫 유효 청소 시점과 완료 시점을 스톱워치로 확인한다. 기준 실측은 총경과에서 **포커스 이탈만 제외**한다. 게임 안에서 고민·도구 교체한 시간은 포함한다. 포커스를 유지한 별도 휴식은 따로 적는다.

한 판 목표는 **3~5분**이나 목표 밖이면 실제 시간을 그대로 적는다. 시간을 맞추려고 기다리거나 반복하지 않는다. 미완료는 관찰 시간을 적고 완료 시간과 구분한다.
