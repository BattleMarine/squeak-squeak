# 뽀득뽀득 Unity 3D 게임 프로젝트 베이스 기획서

## 1. 프로젝트 개요

**뽀득뽀득**은 Unity 3D 엔진을 이용해 개발하는 탑뷰 방식의 3D 클리닝 시뮬레이션 게임이다.

플레이어는 작업대 위에 놓인 더러운 물체를 여러 도구로 청소하고, 다듬고, 광을 내어 깨끗한 상태로 복원한다. 초기 MVP 데모의 핵심 대상은 **더러운 동전**이다.

이 게임은 대규모 전투, 탐험, 스토리 중심 게임이 아니라, 작은 물체 하나를 정성스럽게 닦아내는 과정에서 나오는 시각적 만족감과 반복 플레이를 핵심 재미로 삼는다.

---

## 2. 프로젝트 한 줄 정의

> 뽀득뽀득은 더러운 동전을 다양한 도구로 닦고, 표면을 복원하고, 광을 내어 수집·전시하는 탑뷰 3D 클리닝 시뮬레이션 게임이다.

---

## 3. 프로젝트 목표

### 3.1 거시 목표

Unity 3D 엔진을 활용해 실제로 조작 가능한 작은 규모의 3D 게임을 만들고, Unity 프로젝트의 기본 구조와 개발 흐름을 익힌다.

### 3.2 1차 목표

완성형 상용 게임을 처음부터 만드는 것이 아니라, 하나의 핵심 플레이 루프가 작동하는 작은 MVP 데모를 완성한다.

초기 목표는 다음과 같다.

```text
작업대 위에 동전이 놓인다
플레이어가 도구를 선택한다
마우스 드래그로 동전을 닦는다
오염이 점점 제거된다
동전 표면이 점점 깨끗해진다
광택 도구로 반짝임을 올린다
일정 조건을 만족하면 청소 완료 판정이 뜬다
결과 화면에서 동전의 상태를 확인한다
다시 시작할 수 있다
빌드해서 실행할 수 있다
```

## 4. 개발 방향

이 프로젝트는 처음부터 큰 세계관, 복잡한 상점, 수많은 도구, 고급 그래픽, 정교한 셰이더를 전부 구현하는 것을 목표로 하지 않는다.

초기에는 다음 원칙을 따른다.

```text
1. 작게 만든다.
2. 동전 하나의 청소 루프를 먼저 완성한다.
3. 그래픽보다 조작감과 시각 피드백을 우선한다.
4. 처음에는 임시 에셋과 기본 도형을 사용한다.
5. 기능을 작은 단위로 추가한다.
6. README와 AGENTS.md를 작성한다.
7. AI 도구나 Codex가 이어서 작업할 수 있도록 씬 구성과 스크립트 역할을 문서화한다.
8. 오염 제거 방식은 처음부터 하이브리드 구조를 고려한다.
```

## 5. 장르와 시점

```text
장르: 3D 클리닝 시뮬레이션 / 수집형 반복 작업 게임
시점: 탑뷰
카메라: 작업대 위 동전을 내려다보는 Orthographic Camera
초기 플랫폼: PC
주요 입력: 마우스 드래그
엔진: Unity 3D
언어: C#
```

이 게임의 탑뷰는 캐릭터를 위에서 조작하는 방식이 아니라, 작업대 위의 물체를 내려다보며 도구를 움직이는 방식이다.

플레이어는 캐릭터를 이동시키는 것이 아니라, 선택한 도구를 손처럼 움직여 동전 표면을 청소한다.

## 6. 핵심 게임 콘셉트

플레이어는 더럽고 오래된 동전을 닦는다.

처음에는 먼지, 흙, 검은 때, 물기, 산화 얼룩, 광택 저하 등으로 더럽혀진 동전이 등장한다.

플레이어는 천, 솔, 광택천 등 여러 도구를 사용하여 동전을 깨끗하게 만든다.

게임의 핵심 변화는 다음과 같다.

```text
더러운 동전
↓
큰 오염 제거
↓
표면 얼룩 제거
↓
세부 오염 정리
↓
광택 작업
↓
반짝이는 동전
↓
수집 또는 전시
```

## 7. 핵심 재미

뽀득뽀득의 핵심 재미는 다음 요소에서 나온다.

```text
1. 더러운 물체가 점점 깨끗해지는 시각적 만족감
2. 도구를 직접 문지르는 손맛
3. 오염 종류에 맞는 도구를 고르는 판단
4. 닦은 부분과 닦지 않은 부분이 눈에 보이는 변화
5. 마지막에 동전이 반짝이는 보상감
6. 완성된 동전을 모으거나 전시하는 수집감
7. 랜덤 오염 동전을 반복해서 청소하는 반복 플레이
```

이 게임은 스토리보다 **행위 자체의 만족감**이 중요하다.

따라서 청소할 때의 소리, 먼지가 떨어져 나가는 효과, 표면이 밝아지는 변화, 광택이 살아나는 효과가 매우 중요하다.

## 9. 초기 MVP 범위

초기 MVP는 많은 도구, 많은 동전, 상점, 전시 공간, 랜덤 생성 시스템까지 전부 구현하지 않는다.

초기 MVP의 목표는 다음 하나다.

> 더러운 동전 하나를 도구로 닦아 깨끗하게 만들고, 완료 화면까지 도달한다.

초기 MVP에 반드시 포함할 기능은 다음과 같다.

```text
1. 작업대 위에 더러운 동전 1개가 놓여 있다
2. 탑뷰 카메라로 동전을 내려다본다
3. 플레이어가 도구를 선택할 수 있다
4. 마우스 드래그로 동전 표면을 문지를 수 있다
5. 큰 먼지나 흙 같은 오브젝트형 오염이 제거된다
6. 표면 얼룩이나 색 바램 같은 텍스처형 오염이 점점 줄어든다
7. 광택 도구로 문지르면 동전이 반짝이기 시작한다
8. 청결도와 광택도가 일정 기준을 넘으면 완료 판정이 뜬다
9. 결과 화면에서 동전 상태를 보여준다
10. 다시 시작할 수 있다
```

초기 MVP에서 제외할 기능은 다음과 같다.

```text
여러 종류의 동전
복잡한 상점
도구 강화
랜덤 오염 생성
스토리
세이브/로드
전시 공간 이동
고급 셰이더
정교한 사운드 시스템
복잡한 경제 시스템
```

## 10. 초기 MVP 대상: 기본 낡은 동전

초기 대상은 하나의 기본 동전으로 한다.

```text
동전 이름: 기본 낡은 동전
형태: 원형 동전
초기 상태: 먼지, 흙, 표면 얼룩, 광택 저하가 있는 상태
최종 상태: 깨끗하고 광택이 나는 금속 동전
목표 플레이 타임: 3~5분
```

초기에는 실제 화폐 디자인을 그대로 사용하지 않고, 가상의 동전 디자인을 사용하는 것이 좋다.

이유는 다음과 같다.

```text
저작권이나 실물 화폐 재현 문제를 피할 수 있다
디자인을 자유롭게 단순화할 수 있다
오염과 광택 효과를 테스트하기 쉽다
추후 세계관 없이도 다양한 동전을 추가할 수 있다
```

## 11. 오염 시스템 개요

뽀득뽀득의 오염은 단순한 체력바 하나로 처리하지 않는다.

오염은 성질에 따라 여러 종류로 나누고, 각 오염에 적합한 제거 방식을 적용한다.

오염은 크게 두 가지 방식으로 구현한다.

```text
A 타입: 물리 오브젝트형 오염
B 타입: 표면 텍스처형 오염
```

이 두 방식을 함께 사용하는 하이브리드 구조를 기본 방향으로 한다.

---

## 12. A 타입: 물리 오브젝트형 오염

A 타입은 동전 위에 실제 오브젝트, 데칼, 파티클 조각처럼 배치되는 오염이다.

주로 다음 오염에 사용한다.

```text
큰 먼지
흙덩이
마른 진흙
물방울
이물질
동전 위에 붙은 찌꺼기
```

A 타입 오염은 플레이어가 도구로 문지르거나 긁으면 오브젝트 단위로 떨어져 나가거나 사라진다.

예시:

```text
솔로 흙덩이를 문지르면 작은 조각으로 부서진다
천으로 먼지를 닦으면 먼지 오브젝트가 사라진다
마른 천으로 물기를 닦으면 물방울이 줄어들거나 흡수된다
```

장점:

```text
구현이 비교적 쉽다
눈에 띄는 변화가 크다
즉각적인 피드백을 주기 좋다
오염 제거율 계산이 쉽다
초기 MVP에 적합하다
```

단점:

```text
자연스럽게 표면이 복원되는 표현에는 약하다
오염이 조각 단위로 사라지는 느낌이 날 수 있다
정교한 표면 변화 표현에는 한계가 있다
```

---

## 13. B 타입: 표면 텍스처형 오염

B 타입은 동전 표면의 텍스처, 마스크, 머티리얼 값을 변화시켜 표현하는 오염이다.

주로 다음 오염에 사용한다.

```text
색 바램
산화 얼룩
기름때
찌든 때
얇은 오염막
기스
광택 저하
금속 표면의 탁함
```

B 타입 오염은 도구가 지나간 위치를 기준으로 점진적으로 지워지거나 약해진다.

예시:

```text
천으로 문지르면 기름때 마스크가 조금씩 사라진다
광택천으로 문지르면 표면의 Roughness 값이 낮아져 반짝임이 증가한다
연마 도구를 사용하면 산화 얼룩이 줄어든다
기스는 완전히 사라지지 않고 옅어지는 식으로 처리한다
```

장점:

```text
실제로 표면을 닦는 느낌을 만들기 좋다
오염이 자연스럽게 사라진다
광택 변화와 금속 질감 표현에 적합하다
게임의 완성도를 크게 높일 수 있다
```

단점:

```text
구현 난이도가 높다
RenderTexture, Shader, UV 좌표, 머티리얼 제어가 필요할 수 있다
초기 개발 단계에서 막힐 가능성이 있다
디버깅이 A 타입보다 어렵다
```

## 14. 하이브리드 오염 제거 구조

뽀득뽀득은 처음부터 A 타입과 B 타입을 모두 고려하여 설계한다.

오염 타입별 적용 예시는 다음과 같다.

| 오염 종류 | 적용 방식 | 설명 |
|---|---|---|
| 큰 먼지 | A 타입 | 먼지 오브젝트가 도구에 닿으면 사라짐 |
| 흙덩이 | A 타입 | 솔로 문지르면 조각나거나 떨어져 나감 |
| 물방울 | A 타입 | 천으로 닦으면 흡수되거나 줄어듦 |
| 검은 때 | A+B 혼합 | 겉 찌꺼기는 A, 표면 착색은 B |
| 기름때 | B 타입 | 표면 마스크가 점점 투명해짐 |
| 산화 얼룩 | B 타입 | 특정 도구로만 서서히 제거됨 |
| 색 바램 | B 타입 | 복원 또는 광택 단계에서 머티리얼 변화 |
| 기스 | B 타입 | 완전 제거보다 완화되는 방식 |
| 광택 부족 | B 타입 | Roughness, Smoothness, Specular 값을 조정 |

최종적으로 지향하는 경험은 다음과 같다.

```text
큰 오염은 실제로 떨어져 나간다
표면 오염은 문지른 자리가 자연스럽게 복원된다
마지막에는 동전의 금속 광택이 살아난다
```

## 15. 도구 시스템

초기 MVP 도구는 3개 정도로 제한한다.

도구가 너무 많으면 개발 범위가 커지고, 플레이어도 각 도구의 역할을 이해하기 어렵다.

초기 MVP 도구는 다음과 같다.

```text
마른 천
작은 솔
광택천
```

---

## 16. 도구별 역할

### 16.1 마른 천

역할:

```text
가벼운 먼지 제거
물기 제거
얇은 표면 오염 제거
마무리 작업
```

특징:

```text
오염 제거 속도는 느림
동전 손상 위험 없음
초기 기본 도구
기름때 제거는 가능하지만 효율이 낮음
산화 얼룩 제거는 불가능하거나 매우 느림
```

---

### 16.2 작은 솔

역할:

```text
흙덩이 제거
홈이나 문양 사이 오염 제거
큰 오염 제거
```

특징:

```text
천보다 제거력이 강함
A 타입 오염 제거에 효과적
광택을 올리지는 못함
너무 오래 사용하면 추후 표면 손상 요소를 추가할 수 있음
```

---

### 16.3 광택천

역할:

```text
마무리 광내기
반짝임 증가
결과물 품질 상승
```

특징:

```text
오염이 많이 남아 있으면 효과가 낮음
청소 후반부에 사용하는 도구
광택도 상승에 특화
큰 흙덩이나 먼지 제거에는 비효율적
```

## 17. 도구와 오염 타입의 관계

각 도구는 모든 오염을 똑같이 제거하지 않는다.

도구마다 잘 제거하는 오염 타입을 다르게 설정한다.

| 도구 | A 타입 오염 | B 타입 오염 | 광택 상승 | 비고 |
|---|---:|---:|---:|---|
| 마른 천 | 보통 | 낮음~보통 | 낮음 | 먼지, 물기 제거에 적합 |
| 작은 솔 | 높음 | 낮음 | 없음 | 흙, 찌꺼기 제거에 적합 |
| 광택천 | 낮음 | 보통 | 높음 | 마무리 작업에 적합 |

이 구조를 통해 플레이어는 아무 도구나 문지르는 것이 아니라, 오염 상태를 보고 적절한 도구를 선택하게 된다.

## 18. 도구 확장 후보

MVP 이후 추가할 수 있는 도구는 다음과 같다.

```text
세척액
면봉
부드러운 붓
금속 핀셋
미세 연마제
광택제
초음파 세척기
건조기
확대경
보호 코팅제
```

단, 처음부터 도구를 많이 넣지 않는다.

스테이지 진행에 따라 하나씩 소개하고, 플레이어가 도구의 역할을 자연스럽게 익히도록 한다.

## 19. 진행 구조

초기 진행은 스토리보다 스테이지 방식이 적합하다.

각 스테이지는 새로운 오염 종류나 도구 사용법을 하나씩 소개한다.

예시:

```text
Stage 1: 먼지만 묻은 동전
Stage 2: 먼지와 흙이 있는 동전
Stage 3: 홈 사이에 때가 낀 동전
Stage 4: 표면 기름때가 있는 동전
Stage 5: 광택이 죽은 동전
Stage 6: 산화 얼룩이 있는 동전
Stage 7: 여러 오염이 섞인 동전
```

각 스테이지의 목적은 다음과 같다.

```text
Stage 1: 마른 천 사용법
Stage 2: 작은 솔 사용법
Stage 3: 도구 조합
Stage 4: 표면 오염 제거
Stage 5: 광택 시스템
Stage 6: 강한 오염
Stage 7: 종합 복원
```

## 20. 장기 플레이 구조

초기 스테이지를 모두 완료하고 기본 도구가 해금되면, 이후에는 랜덤 오염도를 가진 동전을 반복적으로 닦는 구조로 확장한다.

반복 플레이 구조는 다음과 같다.

```text
랜덤 동전 생성
↓
랜덤 오염도 부여
↓
플레이어가 청소
↓
결과 등급 산정
↓
보상 획득
↓
동전 수집 또는 전시
↓
상점에서 도구 구매 또는 강화
↓
다음 동전 진행
```

이 구조를 통해 초기 스테이지 이후에도 게임을 계속 이어갈 수 있다.

```text
청소 완료
↓

유리병에 동전 추가
```

이후 확장으로 벽 전시, 진열장, 도감 시스템을 추가할 수 있다.

## 27. 하이브리드 오염 시스템 개발 단계

하이브리드 오염 시스템은 처음부터 최종 형태로 구현하지 않는다.

설계는 하이브리드 구조로 잡되, 구현은 단계적으로 진행한다.

### 27.1 1단계: 단순 하이브리드

```text
A 타입 오염은 오브젝트로 제거
B 타입 오염은 전체 수치 또는 단순 색상 변화로 표현
광택도는 머티리얼 값 변화로 표현
```

### 27.2 2단계: 위치 기반 표면 제거

```text
마우스 드래그 위치를 기준으로 동전 표면의 특정 영역만 오염 제거
원형 브러시 범위 적용
오염 제거율을 위치별로 계산
```

### 27.3 3단계: 텍스처 마스크 기반 제거

```text
RenderTexture 또는 마스크 텍스처 사용
도구가 지나간 부분의 마스크 값을 감소
동전 표면의 오염 텍스처가 자연스럽게 사라짐
```

### 27.4 4단계: 머티리얼/셰이더 고도화

```text
광택도에 따라 Smoothness 또는 Roughness 변경
산화 얼룩과 기름때를 별도 레이어로 분리
기스는 Normal Map 또는 Scratch Mask로 표현
금속 질감과 반사 효과 강화
```

## 35. 최종 정리

뽀득뽀득은 더러운 동전을 깨끗하게 닦는 과정을 중심으로 한 탑뷰 3D 클리닝 시뮬레이션 게임이다.

초기에는 동전 하나를 대상으로 오염 제거, 표면 복원, 광택, 완료 판정까지 이어지는 핵심 루프를 구현한다.

오염 제거 방식은 처음부터 하이브리드 구조로 설계한다.

```text
큰 먼지, 흙, 물기 같은 오염은 A 타입 오브젝트 방식으로 제거한다.
색 바램, 산화, 기름때, 기스, 광택 저하는 B 타입 텍스처/마스크 방식으로 처리한다.
복합 오염은 A 타입과 B 타입을 함께 사용한다.
```

이후에는 동전 종류, 오염 정도, 도구, 상점, 전시, 랜덤 오염 시스템을 확장하여 반복 플레이가 가능한 수집형 클리닝 게임으로 발전시킨다.

최종 방향은 다음과 같다.

> 더러운 동전을 하나씩 정성스럽게 닦고, 표면을 복원하고, 반짝이는 결과물을 모으며, 점점 다양한 도구와 오염 상황을 경험하는 탑뷰 3D 클리닝 시뮬레이션 게임.
