# S3-Rb 수동 확인·Rc 체험

Rb의 기능 확인과 Rc의 사용감 판정을 분리한다. 아래 항목은 **미실행**이며 구현·자동 검사만으로 체크하지 않는다. 실제 진입 방법과 최신 빌드는 [Rb 검증 기록](Step3RbValidation.md)을 따른다.

## 기능 확인

| 확인 | 조작 | 기대 결과 |
| --- | --- | --- |
| [ ] 실험 진입 | 기존 판에서 실험을 선택하고 M1/M2를 각각 시작 | 기존 단계와 실험을 구분할 수 있고 양면에 같은 초기 오염 배치. 실험 도구는 모두 선택 가능 |
| [ ] 문지르기 | 칫솔/천을 누른 채 정지 → 이동 → 정지 | 실제 이동 중에만 유효 오염 제거. 클릭·정지 Hold만으로 제거되지 않음 |
| [ ] 재질 차이 | 두 재질의 미처리 막에 천/칫솔 사용 | M1 천은 막 제거 가능, M2 천과 두 재질의 미처리 칫솔은 막 제거 불가 |
| [ ] 한 방울 | 스포이드 클릭 후 누른 채 이동 | 클릭한 국소 영역만 풀림. 자동 연사·이동 경로 전체 도포·진행률 상승 없음 |
| [ ] 풀림 반응 | 도포 영역과 바깥을 칫솔/천으로 문지름 | 도포한 B 영역에만 바뀐 효율 적용. 약품 단독으로 제거되지 않고 깨끗한 곳은 새 얼룩이 생기지 않음 |
| [ ] 스캐너 | 켜기/끄기, 켠 상태로 닦기, 동전 뒤집기 | 현재 남은 오염만 표시, 제거하면 표시도 감소. 뒷면을 관통 표시하지 않음. 도구 선택·진행률 불변 |
| [ ] 입력 차단 | 도구 사용 중 UI로 이동, MMB/Wheel/F, 창 포커스 전환 | 차단 중 청소/도포 없음. 스포이드는 놓았다 새로 눌러야 재사용. F는 진행을 초기화하지 않음 |
| [ ] 양면·진행 | 한 면만 청소한 후 반대면 청소 | 한 면만으로 완료 불가. 게이지 하나로 집계하며 미완료는 최대99%, A전부/B95% 제거 시100% |
| [ ] 더 닦기 | 100% 후 남은 막을 계속 문지름 | 추가 제거 가능, 강제 트레이 이동 없음, 게이지100% 유지 |
| [ ] 보관 취소 | 보관 확인 열기 → 취소 | 확인 중 입력/시간 정지, 취소 후 오염·풀림·경과 시간 유지 |
| [ ] 보관 확정 | 확정 후 다시 보관을 시도 | 최종 결과1개만 생성, 현재 결과 수정 불가. 시험용 메모리 보관임을 알 수 있음 |
| [ ] 보관 상한 | 시험용 보관함이 찬 상태에서 추가 보관 요청 | 기존 결과를 자동 삭제하지 않고 안내. 취소 후 현재 작업으로 복귀 가능 |
| [ ] 다음 판 | 보관 후 다른 재질의 다음 동전 시작 | 새 판의 초기 오염 복원, 풀림/시간 초기화, 이전 보관 결과 불변 |
| [ ] 포기 취소/확정 | 미보관 상태에서 새 동전 요청 → 취소, 다시 요청 → 확정 | 취소는 작업 유지, 확정만 폐기·새 판 생성. 보관 결과나 보상으로 처리하지 않음 |
| [ ] 종료 | 미보관 상태에서 종료 요청 → 취소, 다시 종료 | 작업 소실 고지, 취소는 유지. 종료 후 미완료 복원 없음. Rb는 보관 결과도 메모리 전용 |
| [ ] 표현·소리 | 유효 제거/무효 문지르기/도포 비교 | 실제 반응과 효과가 일치. 무효 사용에 제거 파편·완료음 없음. 도포는 짧은 방울 소리·국소 표면 변화 |
| [ ] 기존 모드 | 기존 단계 실행·재시작 | 기존 도구 속도/소유 제한/완료 흐름 유지 |
| [ ] 결과 중 진입 | 기존 모드의 완료 연출 중 실험 진입 → 실험 종료 | 옛 UI/트레이가 실험에 겹치지 않고, 종료 후 기존 모드의 UI·도구 제한 복구 |

## Rc 체험 기록

기능표는 개발 검사용이다. 첫 체험 때에는 정답 도구 순서를 알려주지 않고 조작만 안내한다. M1→M2, 이후 M2→M1 순으로 비교한다. 외부 비개발자 체험은 별도이며 이 기록으로 대체하지 않는다.

- 날짜 / 실행 환경 / 빌드:
- 각 동전 완료·보관 시간:
- 도구를 바꾼 이유와 이해하기 어려웠던 반응:
- 세척액의 풀림과 실제 제거를 구분했는가:
- 남은 오염을 찾기 쉬웠는가:
- 도구 교체·클릭·반복 중 번거로운 지점:
- 100% 후 더 닦기와 보관을 구분했는가:
- 더 진행하고 싶은가, 줄이거나 바꾸고 싶은 것은 무엇인가:

Rc의 채택·수정·이월 판정은 사용자 체험 후 기록한다. 실제 광택 표현의 종전 문제와 영구 저장은 이번 실험 통과로 해소 처리하지 않는다.
