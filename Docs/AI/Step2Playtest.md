## 참가자에게 전달할 안내만

> 동전 하나를 원하는 방식으로 깨끗하게 해보세요. 편한 방식으로 체험하시면 됩니다. 중단하고 싶으면 언제든 알려 주세요.

위 인용문만 공유한다. 다음은 진행자 기준이다: 게임 자체의 안내는 그대로 두되 개발자가 키·도구 역할·앞뒤 청소 방법·완료 조건·목표 시간을 설명하거나 시범 보이지 않는다.

## 진행자 준비·관찰

- 구현에 참여하지 않은 사람 최소 1명. 익명 ID `T01`부터 사용하고 이름·연락처는 기록하지 않는다. 개발 참여 여부, 이 게임 첫 체험 여부, 사전 안내/영상/이전 빌드 경험을 확인한다. AI/API 검사·개발자 자신의 플레이를 외부 초보 체험으로 대체하지 않는다.
- 대상은 `Builds/Windows/Step2-20261008-S2-06b/SqueakSqueak.exe`(Windows64/Mono 비개발, 런타임 기준 `3f2011e`). **출력 폴더 전체**를 유지해 전달한다. 파일 전달·업로드·테스터 모집/메시지는 사용자 담당이며 이번 문서 작업에서 수행하지 않았다.
- S2-06b는 빌드/실행 초기화만 확인했다. 실제 입력·셰이더/한글·소리·Player 성능은 미검증이다. 오류·무음·조작 불능을 만나면 억지로 완료시키거나 진행률을 주입하지 말고 발생 상황·중단 여부를 기록한다.
- 설명 없는 자유 체험을 5~10분 관찰한다. 참가자가 일찍 중단하면 강요하지 않고 실제 길이·이유를 남긴다. 빨리 완료해 자발적으로 추가 플레이한 경우도 첫 판과 구분한다. 관찰자가 뒤집기·도구 변경·재시작을 지시하지 않는다. 도움을 요청하면 시점·질문·제공한 안내를 적고 이후 구간은 **도움 있음**으로 분리한다.
- 진행자는 아래 목표/정밀 검사를 첫 체험 전에 노출하지 않는다. 첫 무안내 체험·사후 질문을 마친 뒤에만 b의 정밀 조작 검사를 별도로 진행한다. 그 검사의 설명을 받은 같은 참가자를 다시 처음 보는 초보자로 판정하지 않는다.

### 시간 기록 기준 (진행자 전용)

첫 유효 청소는 **실제 오염/광택 변화 또는 HUD 타이머 시작을 관찰한 시점**이다. 클릭 시작과 구분하고 판단 근거를 적는다. 완료는 결과 화면/완료 판정을 실제 관찰한 시점이다.

- 첫 판 경과 = 완료 시각 − 첫 유효 청소 시각. 포커스 이탈과 별도 중단 구간의 시작/끝·사유를 각각 기록한다.
- **기준 실측 = 첫 판 총경과 − 포커스 이탈 구간의 합집합 길이**다. HUD 대조와 대표3~5분 판정은 이 값을 쓴다. 게임이 활성 상태인 고민·탐색·도구 교체 시간은 빼지 않는다.
- 포커스를 유지한 별도 휴식/중단은 기준 실측에서 자동으로 빼지 않고 **별도 보정값·사유**로 적는다(포커스 이탈과 겹친 시간은 중복 보정하지 않음). HUD/결과 시간은 기준 실측과 대조하며 표시 정밀도·기록 지연·차이·측정 방법(예: 스톱워치)을 기록한다. 휴식 보정값과 HUD의 차이를 타이머 결함으로 판정하지 않는다. HUD 값이나 자동화 소요시간만으로 실측을 대신하지 않으며 시점이 불명확하면 `측정 불가: 이유`를 적는다.
- 미완료 시 관찰 종료 시각, 총 관찰 시간, 첫 청소 이후 경과/제외 구간, 마지막 A/B 제거율·광택과 중단 이유를 기록한다. 미완료 시간을 완료 시간으로 쓰지 않는다.
- 내부 목표는 첫 판 기준 실측 **3~5분**이다. 포커스를 유지한 별도 중단이 있으면 대표 판정의 제약으로 기록하고 중단 없는 판의 재측정 필요를 남긴다. 참가자에게 목표를 알리지 않으며 강제 대기·반복으로 맞추지 않는다. 목표 밖이면 조작/안내·면적/속도·성능·오류·개인차 등의 관찰 근거부터 검토한다.
