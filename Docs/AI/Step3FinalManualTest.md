2026-10-21. **사용자 검사 대기.** S3-07a/b 개발 검증과 구분하며, 아래 결과를 받은 뒤 Step 3 완료 여부를 판정한다. 이전 정상 보고는 [기존 검사](Step3SaveManualTest.md)에 보존한다.

## 실행

- 최종 빌드: `Builds/Windows/Step3-20261021-final/SqueakSqueak.exe`. 실행 파일과 Data/Mono/UnityPlayer를 포함한 출력 폴더 전체를 유지한다. 검증용 `.utmp` 빌드가 아닌 이 정식 빌드를 사용한다.
- 실행 후 `실험 M1`/`실험 M2`를 선택한다. 칫솔·천은 LMB를 누른 채 문지르기, 스포이드는 클릭, MMB 회전, Wheel 확대/축소, F 자세·줌 복원이다.
- 기존 보관 결과는 그대로 사용한다. 검사 때문에 저장 파일을 삭제·편집하거나 오류를 고의로 만들 필요는 없다. 이미 16개가 차 있다면 상한 동작을 기록하고 새 보관이 필요한 항목은 수행 불가로 남긴다.
