# S3-03 저장·복원 수동 검사

작성2026-10-17. **아직 미실행.** 자동 검사와 사용자 검사는 구분한다. 실제 저장 위치·최신 빌드·03a/b 개발 증거는 [저장 검증 기록](Step3SaveValidation.md)을 따른다. 제품 연결이 완료된03b 빌드에서 검사하며 기존 Rb 빌드는 메모리 전용이다.

| 확인 | 조작 | 정상 결과 |
| --- | --- | --- |
| [ ] 보관 후 재실행 | M1을 목표까지 청소→일부 잔여를 남긴 채 보관→종료→재실행 | 보관한 결과가1개 있고 같은 재질·양면 잔여·표면 상태로 열람됨 |
| [ ] 최종 시점 | 목표 달성 후 추가 청소·약품 처리→보관 | 목표 도달 당시가 아닌 보관 확정 시점의 상태가 복원됨 |
| [ ] 여러 결과 | M1/M2를 각각 보관→재실행→각 결과 열람 | 두 결과가 섞이지 않으며 새 판을 청소해도 저장 결과가 변하지 않음 |
| [ ] 관찰 전용 | 보관된 결과를 열고 회전/줌/F/LMB/스포이드 시도 | 자세 관찰 가능, 청소·도포로 보관 결과가 수정되지 않음 |
| [ ] 미완료 제외 | 새 판을 일부 청소→종료 고지 확인→재실행 | 미보관 판은 복원되지 않고 이미 저장된 결과는 유지됨 |
| [ ] 취소 | 보관 확인 또는 판 폐기 확인을 취소 | 현재 작업 유지, 새 저장 결과나 중복 항목 없음 |
| [ ] 오류·상한 안내 | 격리된 검증 환경의 저장 오류/상한 상태 관찰 | 성공으로 표시하지 않으며 기존 결과/현재 작업 유지, 재시도·취소 가능 |

손상/미래 버전·쓰기 실패의 자동 검사는 제품 저장을 직접 편집하지 않고 격리 경로에서 수행한다. 실제 파일로 추가 수동 재현이 필요하면 테스트 복사본과 별도 실행 경로를 먼저 준비한다.

- [ ] 수정본 Alt+Tab 후 회전 붙음 없음, F는 청소/시간 초기화 없이 자세만 복원.
- [ ] 스포이드와 MMB 동시 입력에 의도하지 않은 방울 없음.
- [ ]16개 상한 이후 추가 보관 거부·기존 결과 유지.
- 소리·성능·외부PC·외부 비개발자 체험은 별도 기록한다.
