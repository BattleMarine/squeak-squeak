# S3-03 저장·복원 수동 검사

작성2026-10-17. **2026-10-21 사용자 경량 검사: 주요8항목·입력3항목 정상, 특이사항 없음.** 자동 검사와 사용자 검사는 구분한다. 실제 저장 위치·최신 빌드·03a/b 개발 증거는 [저장 검증 기록](Step3SaveValidation.md)을 따른다. 제품 연결은03b부터 지원하며 최신06 수정본을 사용한다. 기존 Rb 빌드는 메모리 전용이다.

최신 빌드: `Builds/Windows/Step3-20261021-ui/SqueakSqueak.exe` (출력 폴더 전체 유지).

## 실행·확인 순서

- 새 S3-03 빌드 또는 CleaningRoom Play에서 `실험 M1`/`실험 M2` 진입 → 청소 목표 달성 → `보관 확인` → 확인을 누른다. `파일 보관됨` 표시를 확인한 뒤 종료한다.
- 재실행 직후 `보관함` → 저장 항목의 `열람`. MMB/Wheel/F로 앞뒤를 살핀다. 미보관 청소 중에는 열람이 제한되며, 먼저 보관하거나 명시적으로 작업을 폐기한다.
- 제품 저장 위치: `Application.persistentDataPath/SaveData/v1`. 현재 Windows 설정 기준 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/Squeak Squeak/SaveData/v1`이다. 결과와 일반 진행은 각각 별도 `.sqsave` 파일이다. Editor도 검증용 override가 없으면 같은 제품 경로를 사용한다.
- 과거 Rb 빌드의 메모리 보관 결과는 종료 후 복구할 파일이 없으므로 이전되지 않는다. 이번 형식은 실험 M1/M2의 완성 결과만 지원하며 최대16개다.

| --- | --- | --- |

손상/미래 버전·쓰기 실패의 자동 검사는 제품 저장을 직접 편집하지 않고 격리 경로에서 수행한다. 실제 파일로 추가 수동 재현이 필요하면 테스트 복사본과 별도 실행 경로를 먼저 준비한다.

- [x] 스포이드와 MMB 동시 입력에 의도하지 않은 방울 없음(사용자 보고).

## 결과 기록

### S3-06 수정본 추가 확인 (사용자 검사 대기)

- [ ] M1/M2 청소 중 `보관함`을 눌러 제한 안내를 연다. 창이 열린 동안 회전·청소·작업 시간이 멈추고, 닫으면 기존 작업을 이어갈 수 있다.
- [ ] MMB로 회전하며 도구 버튼 위로 이동한다. 회전이 멈추고, 버튼 밖으로 나와도 누른 채로는 재개되지 않는다. MMB를 떼고 다시 누르면 회전한다.
- [ ] F를 UI 위에서 누르면 자세가 바뀌지 않는다. UI 밖에서 누르면 자세·줌만 복원되고 청소 진행·선택 도구는 유지된다.
- [ ] `새 M1/M2` 또는 `실험 종료`의 폐기 확인을 취소하면 현재 동전·오염·시간이 유지된다.
- 긴 오류창의 본문·스크롤·버튼과 16개 상한은 격리 자동 검사로 확인한다. 실제 저장 파일을 고의로 손상시킬 필요는 없으며, 기존 사용자 미확인 항목을 자동으로 완료 처리하지 않는다.

- 날짜/빌드/실행 환경: 2026-10-21 대화 보고. 실행한 빌드/Editor 여부·장치 정보는 별도 명시되지 않음.
- 확인한 항목: 최종 상태 저장, 확인 취소·시간, 재실행 복원, 여러 결과 독립, 미보관 작업 폐기, 중복 클릭, 작업 중 열람, 도구 제한 유지 및 Alt+Tab/F/스포이드+MMB 정상.
- 실패 조작 순서·예상/실제: 특이사항 없음. 경량 사용자 검사이며 자동 검사나 모든 세부 조합 통과로 확대하지 않음.

- 미확인: 관찰 전용의 청소·도포 차단, 별도 판 폐기 확인 취소, 오류 안내. 16개 상한은 사용자가 천천히 검사 후 보고 예정. 보관 확인 취소는 위 항목으로 확인했으며 판 폐기 취소까지 추정하지 않음.
