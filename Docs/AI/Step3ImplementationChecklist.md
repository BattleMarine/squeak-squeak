### 구현 연결점

- `CleaningCompletionController`: 완료 판정과 `RoundCompleted`, `RoundRestarting`, `RoundRestarted`가 기존 연결점. 결과 UI를 상태 소유자로 만들지 않는다.
- `RestartRound()`는 완료된 판만 허용한다. 단계 적용/포기/재개를 위해 공통 초기화와 전환 상태를 분리해야 하며 완료 플래그를 강제로 켜지 않는다.
- `ObjectDirtCleaner`는 Awake에서 A 배열 개수와 Removed 구독을 설정한다. 단계별 A 교체 때 집계·해제/재구독을 함께 처리한다.
- `CoinSurfaceContamination`은 앞뒤 마스크를 소유하고 Reset/해제를 담당한다. `CoinSurfacePointer`/표현/완료의 현재 동전 참조까지 재연결한다.
- `CleaningToolSelection`은 availableTools/defaultTool만 있으며 소유권 검사는 아직 없다. 저장·단계·재화·상점 시스템도 신규 구현 대상이다.

### 2026-10-13 — 문지르기 입력 요구사항 확인

- **[s3-input-f1] 정지 Hold 청소 재현·수정 필요:** 사용자 요구는 LMB를 누르고 실제로 문지를 때만 A/B 제거·광택 적용이다. 현재 포인터는 이동 여부 없이 눌림/표면 접촉을 승인하고, A는 초당량×dt, B/광택은 이동거리0에서도 최소1표본에 초당량×dt를 적용한다. 실제3도구·동일 접촉60프레임(1초) CPU 재현에서 모두60회 B 변화, 마른천/광택천은 광택 증가를 확인했다. 기존 Hold 테스트가 이를 정상으로 기대하므로 S3-02 신규 회귀가 아닌 입력 계약 변경이다.
