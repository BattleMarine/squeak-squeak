- `CleaningCompletionController`: 완료 판정과 `RoundCompleted`, `RoundRestarting`, `RoundRestarted`가 기존 연결점. 결과 UI를 상태 소유자로 만들지 않는다.
- `RestartRound()`는 완료된 판만 허용한다. 단계 적용/포기/재개를 위해 공통 초기화와 전환 상태를 분리해야 하며 완료 플래그를 강제로 켜지 않는다.
- `ObjectDirtCleaner`는 Awake에서 A 배열 개수와 Removed 구독을 설정한다. 단계별 A 교체 때 집계·해제/재구독을 함께 처리한다.
- `CoinSurfaceContamination`은 앞뒤 마스크를 소유하고 Reset/해제를 담당한다. `CoinSurfacePointer`/표현/완료의 현재 동전 참조까지 재연결한다.
- `CleaningToolSelection`은 availableTools/defaultTool만 있으며 소유권 검사는 아직 없다. 저장·단계·재화·상점 시스템도 신규 구현 대상이다.

- **[s3-goal-f1] 기준 문서·강제 범위:** ROADMAP/지시서가 10/15 설계 원칙을 정본으로 안내하지만 최신 GOAL과 충돌하는 종전안이 남아 있다. 도금·복합 구조, 보존 목표, 손상 경고 방식은 미결정/선택 사항이다. Ra/Rc 및 w1의 도금·함몰·보존 검증을 일괄 필수로 두지 말고 채택한 최소 표본에만 적용하도록 개정해야 한다. 참조하는 설계 원칙·스토리보드도 구현 전 해당 부분을 함께 대조한다.
- **[s3-goal-f2] 도구·자동 장비:** ROADMAP Alpha의 자동 대체 금지와 지시서 R-c의 자동 완료 금지는 후반 편의 장비 허용 후보와 충돌한다. 초기 수동 프로토타입 제외와 최종 게임의 금지를 구분한다. 초기6/최종8종 대신 칫솔·스포이드 병·천·이쑤시개/송곳·컴파운드/면봉·오염 확인 장치 중 최소 조합을 선정한다. 보호 도포기는 제외, 젤은 우선 제외다.
- **[s3-goal-f3] 입력·UI:** 현재 문지르기 계약은 닦기/솔질/연마에 유지하되, 스포이드 방울 투입·스캐너·향후 자동 장비까지 이동 필수로 확대하지 않는다. Ra에서 도구별 사용 입력과 효력 조건을 구분한다. S3-06에는 단일 진행 게이지, 작업 중 오염 확인, 작업대 물체로 도구 선택, 표면/효과음 중심 피드백을 반영할 필요가 있다. 정식 3D 배치 구현 시점은 별도이며 기존 버튼은 임시 UI로 유지 가능하다.
- **[s3-goal-f4] 완료·선택 광택:** 지시서의 완료 즉시 입력/수치 고정은 완료 후 선택 광택 후보와 충돌한다. 광택 필수 여부는 미정이므로 확정된 선택 기능처럼 쓰지 않는다. 선택 광택 채택 시 청소 목표 달성과 최종 보관 확정 시점을 나누고, 후처리·나가기·결과 갱신·중복 보상의 규칙을 저장 전에 정한다. 보존 우선 등급·시간 동점 비교·구매 필수 흐름도 확정 요구로 확대하지 않는다.
- **[s3-goal-f5] 저장·이동:** 현 S3-03 DTO는 재화/단계 기록 중심으로 완성 동전 표면 보존을 다루지 않는다. 일반 진행, 디자인, 초기 시드, 완성 결과 데이터의 책임을 구분하고 결과 저장 구현 시점을 명시해야 한다. 미완료 청소는 종료 시 고지 후 폐기하고 방 이동 중에는 유지한다. 작업대에서 명시적으로 새 동전을 생성/교체하며, 전시 이동·화면 복귀를 판 초기화나 강제 포기로 취급하지 않는다. 디자인 제작 중 저장 정책은 별도 미정이다.
- **[s3-goal-f6] 후속 범위·이력:** 스테이지/상점 중심 진행은 기존 시험 기반이며 무한 모드와 최종 경제 채택을 확정하지 않는다. 제작기·공유는 ROADMAP의 후속 후보로 표시하되 Step3 필수나 출시 약속으로 넣지 않는다. 완료된 S3-00~02는 유지한다. 상단의 머티리얼 커밋 제외 문장은 당시 두 작업의 이력으로 명확히 한정해야 한다(현재 663babe에 보존됨).
- **[s3-goal-f7] 다음 작업 제안:** 구현 전 씬 UI·미확정 마스크 참조·광택 표현의 현재 기준선을 확인한다. 이어 Ra를 소수 단일 재질/오염/수동 도구의 효과·반응표, 단일 게이지·완료/보관 규칙, 입력 계약으로 좁힌다. 예시 규모는 재질2·오염2~3·수동 도구3이며 확정 수량은 아니다. 승인 후 Rb 최소 구현→Rc 사용자 체험→채택 범위와 결과 저장 경계 확정→S3-03 순으로 진행한다. 고급 마모·메시 변형·도금·제작기·공유·방 전체 연출은 핵심 반응 실험의 선행 조건으로 두지 않는다.

### 2026-10-16 — GOAL 검토 반영 문서 개정

- **[s3-goal-f8] 개정 완료:** f1~f7을 ROADMAP·Step3 지시서·본 체크리스트의 현재 계획에 반영했다. Ra-1~6 산출물/완료 기준, 조건부 손상·경제, 도구별 입력, 단일 게이지, 완료/보관과 저장 책임을 구분했다. 옛 검토 기록은 당시 이력으로 유지한다. Ra 산출물 작성·기능 구현·Unity 검증·빌드·커밋은 수행하지 않았으며 Ra~07 완료 체크는 미체크다. 문서 diff/상대 링크 검사로 인계 구조를 확인했다.
